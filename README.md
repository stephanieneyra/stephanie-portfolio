## Deploy (Cloudflare Pages)

1. Sube este proyecto tal cual a tu repositorio de GitHub (`stephanie-portfolio`).
2. En Cloudflare Pages, conecta el repositorio.
3. Framework preset: **Astro**. Build command: `npm run build`. Output directory: `dist`.
4. Si el build falla, copia el error del log de Cloudflare — no se pudo probar localmente porque el entorno de construcción no tenía acceso al registro de npm.

## Desarrollo local (opcional, no obligatorio)

```
npm install
npm run dev
```
