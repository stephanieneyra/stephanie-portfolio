title: "Modelo de forecast de demanda"
summary: "Modelo de pronóstico para reducir quiebres de stock y sobreinventario a partir del historial de ventas."
problem: |
  El proyecto analizará cómo estimar la demanda futura para reducir dos problemas frecuentes: faltantes de producto y exceso de inventario. El objetivo será convertir el historial de ventas en una herramienta de apoyo para compras, producción y planificación.
dataSource: |
  Proyecto de práctica con datos históricos públicos o simulados de ventas y demanda. El dataset incluirá fechas, productos, cantidades vendidas y, cuando estén disponibles, variables como promociones, estacionalidad o inventario.
analysis: |
  Se analizará la evolución de la demanda, tendencias, estacionalidad y variaciones por producto o periodo. Se comparará el comportamiento histórico y se construirá un modelo de forecast, evaluando su error para determinar qué tan útil resulta para la planificación.
solution: |
  Se propondrá un forecast de demanda acompañado de una vista que compare demanda real vs. estimada. A partir de los resultados, se plantearán recomendaciones para planificar inventario y priorizar productos con mayor riesgo de quiebre o sobrestock.
results: |
  Proyecto de práctica. El impacto se evaluará mediante métricas del modelo y la utilidad de las recomendaciones generadas. No se atribuirán reducciones reales de inventario, costos o desperdicio sin datos de implementación.
tools: ["Excel", "SQL", "Power BI"]
