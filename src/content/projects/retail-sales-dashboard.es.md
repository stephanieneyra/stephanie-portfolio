title: "Dashboard de ventas retail"
summary: "Panel ejecutivo para detectar tendencias, caídas de desempeño y oportunidades comerciales en ventas retail."
problem: |
  Una empresa retail necesita entender qué productos, categorías y periodos generan mayores ventas y rentabilidad. El objetivo es transformar datos transaccionales en una vista ejecutiva que permita detectar tendencias, caídas de desempeño y oportunidades comerciales.
dataSource: |
  Proyecto de práctica con un dataset público o simulado de ventas retail. Incluye variables como fecha, producto, categoría, unidades, ventas, costos, margen y ubicación. La fuente exacta se indicará en la versión final del proyecto.
analysis: |
  Se limpiarán y organizarán los datos, se crearán KPIs de ventas, unidades, margen y crecimiento, y se analizará el desempeño por periodo, categoría, producto y ubicación. También se identificarán productos con alto volumen pero baja rentabilidad y cambios relevantes en las tendencias.
solution: |
  Se construirá un dashboard interactivo para que un gerente pueda revisar rápidamente el desempeño comercial, filtrar la información y detectar categorías o productos que requieren atención. El proyecto cerrará con recomendaciones basadas en los hallazgos del análisis.
results: |
  Proyecto de práctica. El resultado será un dashboard funcional y un conjunto de insights de negocio obtenidos del dataset. No se presentarán mejoras porcentuales o impactos financieros como reales si no existe evidencia para sustentarlos.
tools: ["Power BI", "Excel", "SQL"]
